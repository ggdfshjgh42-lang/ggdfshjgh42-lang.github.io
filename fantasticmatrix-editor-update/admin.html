连接 GitHub

连接后，你可以直接把修改发布到自己的网站。

  1. 打开 GitHub 授权设置 ↗，新建一个 fine-grained token。
  2. 在 Repository access 中选择 Only select repositories，只选 ggdfshjgh42-lang.github.io。
  3. 在 Repository permissions 中添加 Contents → Read and write，生成后复制授权令牌。

令牌只在当前页面内存中使用，刷新后需重新连接。请勿把令牌发给别人。
